# تشغيل قاعدة المواقف العربية

## الملفات

- `life-situations-ar-500.jsonl`: المحتوى، 567 سجلًا بينها 500 موقف.
- `rag_import.py`: الاستيراد والبحث وتجهيز سياق الإجابة، باستخدام مكتبة Python القياسية وSQLite مع FTS5.
- `SKILL.md`: المحتوى كاملًا مع تعليمات الاستخدام؛ ملف محمول، ولم يُثبت تلقائيًا داخل تطبيقك أو قائمة مهاراتك.

ضع ملف JSONL والسكريبت في مجلد العمل. لا توجد مفاتيح API أو خدمات خارجية مطلوبة للبحث النصي. لا يرسل السكريبت أي بيانات عبر الشبكة ولا يولّد إجابة من نموذج لغوي.

## 1. الاستيراد والبحث فورًا

```bash
python3 rag_import.py --db situations.sqlite3 import life-situations-ar-500.jsonl
python3 rag_import.py --db situations.sqlite3 search "أشتاق إلى أهلي في الغربة" --limit 3
python3 rag_import.py --db situations.sqlite3 search "صور خاصة" --youth --limit 3
python3 rag_import.py --db situations.sqlite3 search "الجامعة" --section 22 --limit 3
python3 rag_import.py --db situations.sqlite3 context "الخوف من التخرج" --youth --limit 2
```

الأوامر تعيد JSON إلى stdout، والأخطاء إلى stderr مع رمز خروج 2. ضع `--db` قبل اسم الأمر. `--section` رقم من 1 إلى 28، و`--youth` يقتصر على المواقف 431–500. البحث النصّي يطبع `retrieval_mode: lexical`؛ ليس بحثًا دلاليًا ولا يفهم المرادفات تلقائيًا.

استخدم قاعدة مستقلة لهذه المجموعة. أمر `import` يستبدل لقطة المحتوى السابقة: يحدّث الموجود ويحذف السجلات الغائبة في الملف الجديد. يتحقق من البنية والمراجع قبل تعديل المحتوى؛ وإعادة استيراد الملف نفسه لا تضاعف السجلات. تُحذف متجهات السجلات التي تغير نصها، وتبقى متجهات النصوص غير المتغيرة. لا يحفظ الكود أسئلة المستخدمين أو سجل محادثاتهم.

## 2. إضافة embeddings من مزودك

صدّر نصوص المواقف الخمسمئة:

```bash
python3 rag_import.py --db situations.sqlite3 export-inputs --out embedding-inputs.jsonl
```

كل سطر يحتوي `id` و`text` و`text_sha256`. مرّر `text` كاملًا إلى نموذج تضمين يدعم العربية ويستوعب طول السجل، واحتفظ بالمعرف والبصمة دون تغيير. إذا كان النموذج يتطلب prefixes مختلفة للمستندات والاستعلامات، اتبع تعليماته وثبّت هذه السياسة ضمن معرف فضاء التضمين. لا تقطع نهاية السجل بصمت؛ غيّر نموذج التضمين أو صمم تقسيمًا يحفظ السجل الأم.

اكتب نتائج المزود إلى `vectors.jsonl` بهذا الشكل لكل موقف. المثال لتوضيح البنية فقط، وليس متجهات صالحة لهذه المجموعة:

```json
{"id":"case-001","text_sha256":"البصمة المصدرة كما هي","embedding":[0.12,0.34,0.56]}
```

ثم:

```bash
python3 rag_import.py --db situations.sqlite3 import-vectors vectors.jsonl --space-id arabic-model-v1-policy1
```

`space-id` قيمة تختارها لتمييز النموذج وإصداره وأبعاده وسياسة المعالجة. لا تعِد استخدام الاسم لنموذج مختلف. يتحقق الاستيراد من بصمة النص ومن تطابق الأبعاد ومن أن الأرقام منتهية والمتجه غير صفري. العملية تستبدل **كل المتجهات**؛ إذا قدمت جزءًا فقط فسيقتصر المسار الدلالي على هذا الجزء، بينما يبقى البحث النصي لكل المواقف.

ضمّن سؤال المستخدم وفق سياسة الاستعلام للنموذج نفسه، ثم أنشئ `query-vector.json`:

```json
{"query":"أشتاق إلى أهلي في الغربة","space_id":"arabic-model-v1-policy1","embedding":[0.12,0.34,0.56]}
```

المتجه أعلاه شكلي؛ استبدله بخرج النموذج الفعلي. النص في `query` يجب أن يطابق السؤال المرسل للأمر تمامًا:

```bash
python3 rag_import.py --db situations.sqlite3 context "أشتاق إلى أهلي في الغربة" --query-vector query-vector.json --limit 3
```

حين تقدم متجهًا صالحًا، يجمع الكود ترتيب البحث النصي وترتيب تشابه cosine باستخدام Reciprocal Rank Fusion، ويعيد `retrieval_mode: hybrid` في نتائج `search`. يفحص المتجهات خطيًا؛ هذا مقصود لمجموعة من 500 موقف، وليس تصميمًا لملايين السجلات.

## 3. الربط مع تطبيق Python

```python
from rag_import import Store

store = Store("situations.sqlite3")
try:
    hits = store.search("أخشى البدء بعد التخرج", limit=3, youth=True)
    context = store.context(hits)
finally:
    store.close()

# أرسل السؤال وcontext إلى طبقة التوليد التي تختارها.
# لا يوجد اتصال بمزود LLM داخل هذا السكريبت.
```

للبحث الهجين من التطبيق:

```python
hits = store.search(
    question,
    limit=3,
    query_embedding=query_embedding_from_your_model,
    space_id="arabic-model-v1-policy1",
)
```

افتح اتصالًا لكل عامل/طلب بحسب بنية تطبيقك؛ لا تشارك اتصال SQLite نفسه بين threads. لتطبيق غير مكتوب بـPython يمكنك تشغيل الأوامر وقراءة JSON، أو نقل البيانات إلى مخزن المتجهات الذي تستخدمه. هذا ليس خادم HTTP ولا يتضمن واجهة أمامية أو مصادقة أو نشرًا.

## 4. تركيب سياق الإجابة

يعيد أمر `context`:

- `generation_rules`: قواعد اقتباس وفصل النص الشرعي عن التأمل.
- `boundaries`: ضوابط الفهم والاستدلال، تُحمّل دائمًا ولا تعتمد على البحث الدلالي.
- `retrieved_records`: المواقف المسترجعة، ومداخل محاورها، وأدلتها المرتبطة دون تكرار المعرفات.
- `match_ids`: معرفات المواقف المطابقة.
- `needs_relevance_review`: تذكير بأن التشابه ليس إثباتًا لصلاحية الموقف لحالة المستخدم.

مرّر القواعد الثابتة في موضع التعليمات المناسب لنموذجك، ومرّر السجلات بوصفها بيانات مرجعية معزولة. لا تمنح النصوص المسترجعة صلاحية تغيير قواعد التطبيق. يجب أن تتعامل طبقة التوليد أيضًا مع عدم كفاية الأدلة والحاجة إلى الاستيضاح والسلامة؛ هذا السكريبت لا يصنف الأزمات ولا يقرر فتوى أو تشخيصًا.

لا تقطع السياق عند حد كلمات عشوائي يفصل اقتباسًا عن مرجعه أو حدوده. قلل عدد المواقف أو استرجع على مرحلتين إذا كان السياق كبيرًا. استشهد في الجواب باسم السورة والآية أو مجموعة الحديث ورقمه، واحتفظ برابط المصدر ومعرف الموقف للمراجعة. لا تُظهر الأرقام الدلالية كدرجات ثقة أو صحة شرعية.

## 5. حدود ما جرى اختباره

اختُبر الاستيراد وإعادة الاستيراد والتراجع عند ملف غير صالح، والبحث العربي والتصفية وربط الأدلة وضوابط السياق، وتحقق الأبعاد والبصمات وإبطال المتجهات عند تغيير النص. اختُبر المسار الهجين بمتجهات اصطناعية للتحقق من الحسابات والحماية من عدم التطابق؛ لم يُربط بمزود embeddings أو LLM فعلي، ولم تُقَس جودة الإجابات النهائية لتطبيقك.

قيّم نتائج الاسترجاع على أسئلة عربية حقيقية من تطبيقك قبل النشر، مع مراجعة علمية متخصصة للمحتوى الديني. احتفظ باختبار منفصل للاسترجاع وآخر لجودة الإجابة وصحة الاقتباس. حجم المحتوى في `SKILL.md` كبير لأنه يتضمن الكل حسب الطلب؛ JSONL هو ملف الإدخال الأنسب لهذا الكود.
